# SmartDraw Android

Native Android painting app built in Kotlin with OpenGL ES 3.0 shaders, pressure-sensitive stylus and touch dynamics, Bezier curve stroke smoothing, dynamic reference color auto-picking, and steady improvement algorithmic painting.

---

## Features

- **GLES 3.0 Hardware Acceleration**: Antialiased circular brush shaders, directional smudge shaders, and multi-layer compositing over FBOs.
- **Stylus & Touch Pressure Sensitivity**: Continuous `MotionEvent.getPressure()` tracking with customizable response curves (linear, gamma, sigmoid) mapped to brush radius and flow.
- **Bezier Curve Stroke Smoothing**: Multi-point cubic Bezier curve fitting with arc-length parameterization for uniform stamp spacing.
- **Dynamic Color Auto-Picker**: Samples reference image colors dynamically along stroke paths.
- **Steady Improvement Painting Loop**: Autonomous iterative painting loop minimizing MSE difference against reference images.
- **Pragmatic Bezier Test Harness**: Automated test suite generating 30–200 varied Bezier strokes with visual PNG exports and emulator verification.
